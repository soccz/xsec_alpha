# 60회가 끝난 뒤: 기다리는 대신 확인한 것

분석일: 2026-09-30. 대상은 종료된 `short_rank_20260907T054514Z`의
**고정 모델 SHORT 순위 실험 60회**다. 현재 텔레그램 추천 전체의 성적표가 아니다.
모든 수치는 동일 비중 바스켓의 **6시간 회차별 Upbit 대리 가격·가정 비용 성과**다.
누적 계좌 수익이나 실제 Bitget 체결 수익으로 해석하지 않는다.

## 결론부터

1. 모델의 평균은 양수지만 안정적인 수익이나 기준선 대비 우위는 아직 입증되지 않았다.
2. 일부 좋은 회차가 평균에 상당히 기여한다. 큰 이익을 제외해 보니 부호가 바뀌었다는
   사실은 취약성 점검이지, 그 회차를 삭제해야 한다는 뜻이 아니다.
3. 국면별 차이는 후속 가설로 남길 가치가 있지만, 자료가 한쪽에 치우쳐 있다.
   지금 발견한 유리한 국면만 골라 과거 실험을 성공으로 바꾸지 않는다.
4. 작은 개선을 확인하려면 생각보다 긴 관찰이 필요하다. 임의로 60회를 더 기다리는
   대신, 실용적인 개선 폭과 실험 목적을 먼저 구분한다.

## 실제 숫자

| 지표 | 고정 모델 | 반전 기준선 |
| --- | ---: | ---: |
| 평균 net / 회차 | +0.2104% | -0.2900% |
| 중앙값 net / 회차 | -0.0318% | -0.0908% |
| 양수 회차 | 30 / 60 | 28 / 60 |
| 최악 회차 | -13.3492% | -13.0886% |
| 하위 6회 평균 | -7.7360% | -10.6182% |

모델이 기준선보다 나았던 회차는 **32/60**이다. 두 방식의 평균 차이는
**+0.5004%p**, 원래 사전등록된 95% 구간은 **[-0.2351, +1.3183]%p**였다.
최종 판정 `inconclusive`는 변경하지 않았다.

### 좋은 몇 번에 얼마나 기대고 있는가

- 모델 수익이 가장 높았던 3회를 뺀 나머지 57회의 평균: **-0.4048%**.
- 이 3회가 전체 양수 회차의 이익 합계에서 차지하는 비중: **35.62%**.
- 모델-기준선 차이가 가장 컸던 3회를 빼면 나머지 평균 차이: **+0.0830%p**.
- 가장 큰 양의 종목 기여 하나만 0으로 놓으면 모델 평균: **+0.0702%**.

회차 제외는 단순 영향도 진단이다. 종목 기여는 각 회차의 기존 1/5 비중과
전체 60회 분모를 유지해 합산했다. 남은 종목의 비중을 키우지 않았다.
상위·하위 종목별 전체 내역과 회차별 표는 비공개 로컬 `report.json`에 남긴다.
종목을 향후 금지하거나 선호하도록 변경하지 않았다.

### 마지막 구간은 무엇이 달라졌나

| 시간순 20회 | 모델 net | 기준선 net | 모델-기준선 |
| --- | ---: | ---: | ---: |
| 처음 | +0.0455% | -0.5579% | +0.6034%p |
| 중간 | +0.3499% | -1.1153% | +1.4652%p |
| 마지막 | +0.2359% | +0.8034% | -0.5675%p |

**마지막에 모델의 절대 성과가 음수로 바뀐 것이 아니다. 기준선이 더 잘했다.**
따라서 필요한 질문은 단순히 "모델이 망가졌나"가 아니라
"어떤 조건에서 기준선과 모델의 상대적 유용성이 달라지나"다.
세 구간은 결과 확인 후 나눴고 서로 다른 시장을 포함하므로 인과적 설명은 아니다.

## 시즌 가설의 근거와 한계

| 재구성한 BTC 국면 | 회차 / UTC 날짜 수 | 모델-기준선 평균 |
| --- | ---: | ---: |
| 하락·고변동 | 1 / 1 | +0.7240%p |
| 하락·저변동 | 37 / 11 | +1.2210%p |
| 상승·고변동 | 9 / 3 | +0.5527%p |
| 상승·저변동 | 13 / 4 | -1.6039%p |

모든 국면을 숨김없이 표시했다. 1회 또는 3~4일 관찰로 해당 시장의 법칙을
판단할 수 없다. 국면과 달력 구간이 겹치므로 시기·종목 구성 차이와도 분리되지 않는다.

이 표의 국면은 **지금 보관된 과거 BTC 원시 봉으로 사후 재구성**했다.
각 신호 직전 완성 봉과 그 이전 자료만 사용하고 미래 봉을 추가해도 기존 라벨이
바뀌지 않는 것을 테스트했다. 그러나 당시 저장한 국면도 아니고, 과거 가격 DB의
수정 이력도 없으므로 새 prospective 관찰 원장의 증거로 편입하지 않는다.

시장 국면을 연구할 이유는 [Ang·Timmermann의 문헌](https://www.nber.org/papers/w17182)에서도
찾을 수 있다. 문헌이 이 코인 전략의 수익성이나 위 네 국면의 최적성을 보증하지는 않는다.

## 운영 추천과 같지 않다는 점도 확인

- 모델이 선택한 300개 종목-회차에는 고유 종목 93개가 있었다.
- 모델과 반전 바스켓은 평균 **2.15/5개**가 겹쳤다.
- 고정 실험과 당시 actionable 운영 추천은 평균 **2.87/5개**가 겹쳤다.
- 34/60회에는 운영 모델 해시가 고정 실험 모델과 달랐다. 재학습과 게이트·버퍼가
  있는 운영 추천의 성과를 이 실험 결과와 동일시하면 안 된다.
- 선택된 300개 종목-회차 중 60개에는 원래 결측인 입력이 기록되어 있었다.
  기존 입력 처리의 흔적이며, 그 자체로 실패 원인이나 부정확한 예측임을 뜻하지 않는다.

전체 게이트별·신호 시간별·운영 모델 일치 여부별 표도 산출물에 남겼다.
게이트는 무작위 배정이 아니므로 해당 표를 게이트의 개선 효과라고 부르지 않는다.

## 비용이 조금만 달라져도

기존 가정 비용은 회차당 30bp다. 여기에 양쪽 방식에 동일하게 10/20/30bp를
추가하면 모델 평균은 각각 **+0.1104%, +0.0104%, -0.0896%**다.
같은 비용을 빼므로 모델-기준선 차이는 변하지 않는다.
즉, 상대적 우위와 절대 수익성은 별개의 질문이다.
향후 전환 방식에만 드는 추가 비용은 상대적 우위에서도 차감해야 한다.

## 다음 실험은 얼마나 필요한가

단위는 코인 300개가 아니라 **짝지은 회차 60개**다. 차이의 표준편차는 3.0949%p.
IID 분산과 4/8회 연속 블록의 분산 추정 중 가장 큰 값 9.5782 (%p)^2을 사용했다.
원래 검정 결과를 다시 판정하지 않고, 향후 표본 설계에만 사용한다.

양측 유의수준 5%, 목표 검정력 80%의 정규 근사:
`N = ceil_to_4((z(.975) + z(.8))^2 * variance / effect^2)`.
이 식의 출처와 가정은 [NIST 표본 크기 안내](https://www.itl.nist.gov/div898/handbook/prc/section2/prc222.htm)다.
시간 블록은 [시계열 bootstrap 설명](https://bashtage.github.io/arch/bootstrap/timeseries-bootstraps.html)을
참고했고, 기존 저장소의 circular-block 방식을 재사용했다.

| 확인하려는 차이 | 기본 필요 회차 / 이상적 일수 | 분산 1.5배 가정 회차 / 일수 |
| --- | ---: | ---: |
| 0.50%p | 304 / 76일 | 452 / 113일 |
| 0.25%p | 1,204 / 301일 | 1,808 / 452일 |
| 0.10%p | 7,520 / 1,880일 | 11,280 / 2,820일 |

**이 숫자는 정확한 보장이나 적응형 전환 실험의 표본 수가 아니다.** 짧은 과거
자료의 분산이 미래에도 비슷하다는 가정이고, 비정상성·두꺼운 꼬리·새 국면은
이를 깨뜨릴 수 있다. 하루 네 회차가 모두 유효한 이상적 기간이며 국면별 관찰은
더 오래 걸린다. 결측 10% 가정과 분산 2배 시나리오도 JSON에 포함했다.
0.50%p를 골라 더 작은 효과도 검증됐다고 주장하지 않는다.

## 이번 분석으로 정한 방향

"60회를 더 보면 결론이 날 것"이라는 기대는 버린다. 먼저 **국면 전환 후보를
84일짜리 별도 실행 가능성 파일럿으로 평가하는 설계**를 마련했다.
이는 수익 우위 확정 실험이 아니다. 전환이 실제로 얼마나 발생하는지,
바뀐 비중에 비용을 붙이면 무엇이 남는지, 해당 비교값의 분산이 얼마인지가 목적이다.

규칙·평가 시각·최소 유지·비용·종료 분기는 [후속 설계](rotation_followup.md)에 적었고
순수 연구 함수로 구현해 미래 결과 차단, 중복 주간 검토, 냉각 기간 등을 테스트했다.
**설계와 테스트 완료를 실제 파일럿 등록·실행 완료로 표현하지 않는다.**
현재 자동 실행 중인 것은 기존 국면 관찰이며, 전환 후보는 운영에 연결하지 않았다.

